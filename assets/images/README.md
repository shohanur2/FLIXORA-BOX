# FLIXORA home logo

Upload the FLIXORA logo image in this folder with this exact filename:

`flixora_logo.png`

Final path required by the app:
`assets/images/flixora_logo.png`

Recommended image: square PNG (512x512 or larger), transparent background, with the logo centered and a little clear space around it.

After uploading the PNG, tell ChatGPT so the Flutter asset declaration and home search-bar logo can be connected. Do not rename or replace `assets/app_icon.png`; that file is used for the app launcher icon.
